subject_tracking_data_qa

A data-quality check for EarthRanger tracking setups. It fetches every subject, tracking device (source) and assignment between them, and draws them as a single interactive diagram so you can see at a glance which animal wears which collar, since when, and what looks wrong.

What the diagram shows

Subjects are listed on the left and sources on the right. Each assignment is a line between them, labelled with its date range (e.g. 2024-03-01 → present).

You seeIt means
Solid dark lineA current assignment (no end date)
Grey dashed lineAn ended assignment
Red line and label marked ⚠An assignment whose start or end date can't be read
Pill with an amber outline, listed at the bottomA subject with no source, or a source with no subject
Grey-filled subject pillAn inactive subject
Source pill with a red outlineAn assignment points at a source that isn't in the sources list

Hover a subject or source to fade everything else and trace its links. Hover a line or pill for full details (subject type, provider, model, full name).

Requirements

  • Access to an EarthRanger site, set up as a data source connection. The account needs read access to subjects, sources and subject sources.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL. Once added, select subject_tracking_data_qa from the available templates list to load it.

2. Configure the workflow

You'll be prompted to fill in the following parameters before running.

Set Workflow Details

FieldDescriptionDefault
Workflow Name (required)A name for this run.—

FieldDescriptionDefault

Get Subjects

FieldDescriptionDefault
Subject Group NameOnly check subjects in this group. Leave empty for all subjects.All subject groups
Include Inactive (advanced)Include inactive subjects.On
Tracks (advanced)Also fetch recent tracks per subject. Not used by the diagram; leave off.Off

Filtering by subject group limits the subjects and their assignments. Sources are always fetched for the whole site, so every source not assigned to one of the chosen subjects appears under Sources with no subject.

3. Results

The run produces one dashboard with the diagram, and saves the diagram's HTML file to the results folder (ECOSCOPE_WORKFLOWS_RESULTS).

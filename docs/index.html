subject_tracking_master_plot

A data-quality check for EarthRanger tracking setups: every subject, tracking device (source) and assignment between them, drawn as one interactive diagram so you can see which animal wears which collar, since when, and what looks wrong.

What the diagram shows

Subjects are listed on the left and sources on the right. Each assignment is a line between them, labelled with its date range (e.g. 2024-03-01 → present).

You seeIt means
Solid dark lineA current assignment (no end date)
Grey dashed lineAn ended assignment
Red line and label marked ⚠An assignment whose start or end date can't be read
Pill with an amber outline, listed at the bottomA subject with no source, or a source with no subject
Grey-filled subject pillAn inactive subject
Source pill with a red outlineAn assignment points at a source that isn't in the sources list

Hover a subject or source to fade everything else and trace its links. Click one for a details card, including its EarthRanger ID and assignments, with a Copy button. All text in the diagram can be selected and copied.

What it does

StepWhat it does
Set Workflow DetailsNames the run, so its dashboard can be told apart from others.
Set GroupersNo grouping: the dashboard has a single view.
Set Er ConnectionConnects to the EarthRanger site you pick.
Get SubjectsFetches subjects, optionally only one subject group. Stops the run if none are found.
Get SubjectsourcesFetches all subject–source assignments on the site.
Get SourcesFetches all sources (tracking devices) on the site.
Draw Subject Source DiagramDraws the diagram as a self-contained HTML page, including sources not assigned to any subject.
Persist TextSaves the HTML page to the results folder.
Create Plot Widget Single ViewWraps the page in a dashboard widget titled Subject Tracking Master.
Gather DashboardBuilds the dashboard from that widget.

Requirements

  • Access to an EarthRanger site, set up as a data source connection. The account needs read access to subjects, sources and subject sources.

User Guide

How to load subject_tracking_master_plot, connect its data sources and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select subject_tracking_master_plot from the templates list.

2. Data sources

  • Access to an EarthRanger site, set up as a data source connection. The account needs read access to subjects, sources and subject sources.

3. Settings

The run form asks for these. Fields with a default can be left as they are. Advanced fields are hidden until you show advanced settings.

Filtering by subject group limits the subjects and their assignments. Sources are always fetched for the whole site, so every source not assigned to one of the chosen subjects is listed under Sources with no subject.

4. Run it and find the results

The run produces one dashboard with a single widget, Subject Tracking Master, holding the diagram. The same diagram is saved as a self-contained HTML file in the results folder the runner gives it (ECOSCOPE_WORKFLOWS_RESULTS); it opens in any browser.

5. Read the diagram

Subjects are on the left, sorted by name; sources are on the right; the middle column shows each assignment's date range. A subject with several assignments spans one row per assignment.

6. Look up and copy details

  • Hover a subject or source to fade everything unrelated and trace its links. Hover any pill or line for its details as a tooltip: a subject's type and subtype, a source's provider, type and model, and names cut short with ….
  • Click a subject or source to open a details card beside it. It shows the full name, the EarthRanger ID, the same type or provider fields, and every assignment with the subject or source on the other end and its dates. Copy copies the whole card, ready to paste into a spreadsheet, email or ticket. To copy just one value, such as the ID, select it in the card. Close the card with ×, Esc or a click elsewhere.
  • Select and copy any text in the diagram as you would on a web page: drag down a column to pick several names, or double-click one. Copying gives one value per line, and names cut short with … copy in full.

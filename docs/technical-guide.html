Technical Guide

The steps subject_tracking_data_qa runs, the packages they come from, and how to recompile and test it.

Steps

In the order they run. Each step is a task from one of the packages below.

Recompiling

spec.yaml is the source; ecoscope-workflows-subject-tracking-data-qa-workflow/ is generated from it by wt-compiler.

./dev/recompile.sh --update   # keeps the lock file and bumps VERSION.yaml
./dev/recompile.sh --install  # a new lock file, and the packages installed

Testing

Each case in test-cases.yaml runs the workflow with its settings:

pixi run --manifest-path pixi.toml -e default bash dev/pytest-cli.sh subject_tracking_data_qa --all
